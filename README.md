# ひとり、なのに満員御礼。 ─ 6人の役員と1匹の悪魔、ときどき、もう1脚

> 「ひとりは寂しくない。6人と、1匹、ときどき、もう1脚いる。」

ひとり会社の代表が、自分の中に **CEO・CMO・CTO・COO・CFO** と **悪魔役の一匹** を立てて、毎週日曜に取締役会を開いた半年間の議事録 ── 中編ビジネスエッセイ。番外編では、もうひとりのひとり会社経営者から借りた **8 脚目の声（CPO）** が、ときどき会議に座ります。

## 著者について

**粟田Kenny**。株式会社アツメ代表。
「難しい問題を解く人の余計な作業を、減らす」を判断軸に、ひとりで複数の SaaS と顧問先を回すソロプレナー型経営者。本書の本編（プロローグ〜第10回・エピローグ）の著者。

**濱田優貴**（共著）。株式会社イネブラ（Enabler Inc.）代表取締役。メルカリでプロダクト責任者を務めたのち、ひとり〜少人数での「速く、ノイズなく」なものづくりに回帰したソロプレナー型経営者。本書では番外編「8 脚目の椅子」に、議長の内なる CPO の声として参加。柔術青帯。
