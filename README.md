# 6人の役員と1匹の悪魔 ─ ひとり会社の取締役会

> 「ひとりは寂しくない。6人と、1匹いる。」

ひとり会社の代表が、自分の中に **CEO・CMO・CTO・COO・CFO** と **悪魔役の一匹** を立てて、毎週日曜に取締役会を開いた半年間の議事録 ── 中編ビジネスエッセイ。

- **著者**: 粟田Kenny
- **発行**: Atsume Press
